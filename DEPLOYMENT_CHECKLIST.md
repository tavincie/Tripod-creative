# Deployment Checklist

Tripod Creative Agency is prepared for Vercel deployment with Next.js App Router, `next-intl`, local media assets, and WhatsApp booking redirects.

## Required Vercel Settings

- `Framework Preset`: Next.js
- `Build Command`: `npm run build`
- `Install Command`: Vercel default, or `npm ci`
- `Output Directory`: Vercel default
- `NEXT_PUBLIC_SITE_URL`: optional but recommended for final canonical URLs

The app falls back to Vercel-provided deployment URLs and then to `https://tripod-creative.vercel.app`, so builds do not fail when `NEXT_PUBLIC_SITE_URL` is absent.

There are currently no service detail, portfolio detail, booking page, package page, Privacy Policy, or Terms and Conditions routes in this app.

## Production Checks

Run before pushing or deploying:

```bash
git diff --check
npm run lint
npm run build
```

After deployment, check the production URL for:

- Header navigation and locale switching
- Footer links and contact actions
- WhatsApp redirects using `+255 689 430 743`
- Contact form validation and generated WhatsApp message
- Booking modal validation and generated WhatsApp message
- Portfolio filtering
- Mobile layout at common phone widths
- `/robots.txt` and `/sitemap.xml`
- Browser console errors

## Production Notes

- WhatsApp booking uses the fixed launch number `255689430743`.
- Canonical and alternate metadata use `NEXT_PUBLIC_SITE_URL`, Vercel URLs, or the configured production fallback.
- Sitemap and robots routes are generated by Next.js metadata routes.
- The old floating WhatsApp button is not part of the current site.

## Before Custom Domain Launch

- Set `NEXT_PUBLIC_SITE_URL` to the final custom domain.
- Redeploy after the environment variable update.
- Recheck canonical URLs, language alternates, and social previews.
- Confirm whether a branded Open Graph image should be added for richer link previews.
